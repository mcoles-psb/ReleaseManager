Read-only: the databases are only looked at, never changed. Items of a table that exists on one side only are not listed separately; the table's own row covers them. Export CSV saves the rows currently shown to the Reports folder. Get Script writes a script for the rows you tick that makes the target match the source. Run it on the target yourself: as it is, it is a preview (every step runs and is reported, then everything is rolled back); set rm__apply to true at its top to apply. Steps that would lose data fail with the reason, steps already done are skipped, and nothing is ever removed. Release Manager never runs it.
